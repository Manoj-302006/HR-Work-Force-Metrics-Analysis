Workforce Metrics Analysis 📊

An interactive HR analytics solution designed to transform raw workforce data into actionable business insights using Power BI. Because apparently companies need dashboards to realize employees quit when they’re underpaid, overworked, and trapped in meetings that could’ve been emails. Fascinating species, humans.

🚀 Overview

This project analyzes employee and workforce data to help organizations monitor key HR metrics such as employee performance, attrition, attendance, department-wise distribution, salary trends, and workforce productivity.

The dashboard integrates multiple data sources including Excel and HR datasets to provide real-time visual insights for smarter workforce planning and decision-making.
